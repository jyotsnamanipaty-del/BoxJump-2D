# Box Jump 2D

A 2D pixel-art platformer game developed using Unity, featuring coin collection, level completion, and a leaderboard system.

## About the Project

Box Jump 2D is a simple 2D platformer where players navigate through a level, collect coins, and reach the finish point. The game also includes a main menu, tutorial instructions, and a leaderboard to track the fastest completion times.

## Features

- **2D Pixel-Art Gameplay** – A simple and engaging platformer experience.
- **Coin Collection** – Collect coins while progressing through the level.
- **Level Completion** – Reach the finish point to complete the level.
- **Main Menu** – Navigate through the available game options.
- **How to Play** – Learn the controls and gameplay instructions.
- **Tutorial Popup** – Step-by-step instructions for new players.
- **Leaderboard** – View the fastest level completion times.
- **Camera Follow** – Smooth camera movement that follows the player.

## How to Run

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add Project from Disk**.
4. Choose the downloaded Box Jump 2D project folder.
5. Open the project using a compatible Unity version.
6. Open the main menu scene and press **Play**.

## Project Structure

- `Assets/` – Game scripts, scenes, sprites, UI, and other resources.
- `Packages/` – Unity package dependencies.
- `ProjectSettings/` – Unity project configuration.
- `.gitignore` – Excludes generated files from Git tracking.
